#### **Lab: Creating a 'Contact Me' Form**

* **Level 1: Basic Form Structure**  
  * **Tasks:** On your contact.html page, create a basic \<form\> with \<input\> fields for "Name" and "Email," and a \<button\>.  
  * **Outcome:** A raw, unstyled, but structurally complete HTML form.  
* **Level 2: Semantic and Accessible Form**  
  * **Tasks:** Add a \<label\> for each input. Correctly connect them using the for attribute on the label and a matching id attribute on the input.  
  * **Outcome:** An accessible form that is easier for all users to navigate.  
* **Level 3: Styling the Form**  
  * **Tasks:** Apply your portfolio's existing theme (colors, fonts) to the form elements. Use the Box Model (padding, margin) to space out the labels, inputs, and button for a clean, readable layout.  
  * **Outcome:** A form that is visually consistent with the rest of your website.  
* **Level 4: Interactive Feedback**  
  * **Tasks:** Add a :hover style to the submit button to change its background color. Add a :focus style to the input fields to change their border color when a user clicks into them. Commit your changes to Git with a message like "feat: Build and style contact form".  
  * **Outcome:** A form that provides clear visual cues to the user, with all changes tracked in Git.  
* **Level 5: Polished Transitions**  
  * **Tasks:** Apply a CSS transition to the properties you styled in Level 4 (e.g., background-color, border-color).  
  * **Outcome:** A professional and polished form where interactive effects are smooth and animated, enhancing the overall user experience.
